7. INHERITED SCRIPTS CHANGED HERE (GPLv2, from Appointment Hour Booking 1.5.98)
------------------------------------------------------------------------------
These files come from the upstream GPLv2 package and are licensed under GPLv2 (LICENSE.txt).
They were renamed and changed for this plugin. GPLv2 section 2(a) requires each changed file
to carry a prominent notice of the change. The list below records the changes; the notice
inside each file is a separate task (see REQUESTS in the report).

tzfd-calendar/js/jquery.calendar.js
  Beautified from the minified upstream file mv/js/jquery.calendar.js (one line, 92,252
  bytes). The changes below were found by comparing the parse trees of the two files
  (acorn 8, checked 2026-10-14). The beautified file is not the same code as upstream:
  - identifiers and strings renamed from cp to tzfd (for example cpwrap to tzfdwrap and
    cpeoplebrowser to tzfdbrowser);
  - three eval() calls removed: the date constructor, option.rowsByCategory (now
    window[option.rowsByCategory]) and option.dayWithColumns (now window[option.dayWithColumns]);
  - three inline javascript: click handlers in calendar cell objects removed (two "more
    event" alerts and one void(0) link);
  - the event dialog that opened an iframe is replaced: when option.dlgiframe is set the
    event editor opens in a new tab through tzfdOpenInNewTab() (defined in tzfd-calendar/js/Common.js).

js/tzfdform-admin.js
  Beautified from the minified upstream file js/fbuilder-admin.js (one line, 101,549 bytes).
  The changes were found the same way:
  - identifiers, ids and text renamed from fbuilder and cp to tzfdform and tzfd (for example
    the controls registry and the "helpfbuilder" and "apphourbk_cmadmin" names);
  - two eval() calls removed; the control objects are created from $.tzfdform.controls;
  - the placeholder text "available only in commercial version" in the field definitions is
    replaced by the field's own markup.

Other inherited files:
  - js/tzfdform-admin-fields/*.js and js/tzfdform-core-*.jquery.js: renamed from the upstream
    js/fields-admin/ folder and js/fbuilder-pro-*.jquery.js. Their content was not compared line
    by line in this pass.
  - js/jquery.validate.js: see section 3. js/jQuery.stringify.js: see section 6.
  - js/chart.js: replaced by Chart.js 4.5.1, see section 2.
  - captcha/captcha.php: rewritten as an adapter for includes/class-tzfd-captcha.php. The file
    has no licence line of its own and is covered by the plugin licence (GPLv2).
  - tzfd-calendar/css/* and tzfd-calendar/language/*.js: renamed from the upstream mv/ folder.
    The files checked are byte-identical to their upstream files (calendar.css, main.css and the
    language files).
  - Other files from the upstream package (addons/, controllers/elementor/, css/, templates/,
    the rest of js/ and tzfd-calendar/js/Common.js, jquery.alert.js, tzfdcalendar.js) were
    renamed or changed. A complete file-by-file list of these changes is not in this release;
    UPSTREAM.txt records the verified ones.

9. PHP LIBRARIES
